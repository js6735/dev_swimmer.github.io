새 글은 `content/posts/<카테고리>/` 폴더에 `.md` 파일을 만들어 시작합니다. 폴더 이름이 곧 주제이므로 frontmatter에 category를 따로 적지 않습니다.

## frontmatter

| 항목 | 설명 |
| --- | --- |
| title | 글 제목 |
| date | 작성일 (2026-10-12 형식). 최신 글이 위에 옵니다 |
| tags | 태그 목록 |
| summary | 목록에 보이는 한두 줄 요약 |
| draft | `true`면 배포에서 제외 |

### 파일 이름

파일 이름이 주소가 되므로 영문 소문자, 숫자, 하이픈으로 짓는 것을 권장합니다. 주소에는 폴더 이름이 들어가지 않으므로, 다른 폴더에 있더라도 파일 이름이 겹치면 빌드가 실패합니다.

## 이미지

이미지는 `public/images/`에 넣고 `/images/`로 시작하는 경로로 적습니다. 저장소 이름이 붙는 배포 주소에서도 경로가 자동으로 맞춰집니다.

```md
![설명](/images/example.png)
```
